# Adeeb Cash Flow - Vercel Frontend + Render Backend

A full-stack cash-flow application with a static frontend on Vercel, an Express API on Render, and MongoDB Atlas.

## Project structure

- `frontend/` - static signup, login, and dashboard UI
- `backend/` - Express API, authentication, and MongoDB models
- `api/[...path].js` - same-origin Vercel proxy to the Render API
- `render.yaml` - Render Blueprint configuration
- `vercel.json` - Vercel static routes and Function settings

## Local setup

1. Copy `.env.example` to `.env`.
2. Set `MONGODB_URI`, a random `JWT_SECRET` of at least 32 characters, and `ADMIN_EMAIL`.
3. Run `npm install`, then `npm run dev`.
4. Open `http://localhost:3000`.

## Production deployment

Deploy Render first and Vercel second.

### 1. MongoDB Atlas

1. Create a database user and copy the Atlas connection string.
2. In Atlas Network Access, allow Render to connect. For the simplest setup, add `0.0.0.0/0` and use a strong database password.
3. Never commit the connection string.

### 2. Render backend

1. Push this repository to GitHub.
2. In Render, choose **New > Blueprint**, connect the repository, and use the included `render.yaml`.
3. Enter these prompted values:
   - `MONGODB_URI` - full MongoDB Atlas connection string
   - `ADMIN_EMAIL` - account email that should become admin on signup
   - `FRONTEND_URL` - Vercel production origin, such as `https://your-app.vercel.app` (a temporary placeholder is okay until Vercel is created)
4. Render generates `JWT_SECRET`. Do not add this secret to Vercel.
5. Check `https://YOUR-SERVICE.onrender.com/api/health`. It should return `{"ok":true,...}`.

Render environment summary:

```env
NODE_ENV=production
SERVE_FRONTEND=false
MONGODB_URI=<secret Atlas URI>
JWT_SECRET=<generated by Render>
ADMIN_EMAIL=<your admin email>
FRONTEND_URL=https://your-app.vercel.app
```

### 3. Vercel frontend

1. Import the same GitHub repository.
2. Select **Other** as Framework Preset and keep the repository root as Root Directory.
3. Add this environment variable to Production and Preview:

```env
BACKEND_URL=https://YOUR-SERVICE.onrender.com
```

Do not add a trailing slash. Deploy the project, copy its final URL into Render's `FRONTEND_URL`, and restart or redeploy Render once.

The browser calls Vercel's `/api/*` path. Vercel forwards those requests to Render, so authentication cookies remain first-party. MongoDB and JWT secrets are never shipped to frontend JavaScript.
